# MC-CORE-DEV

Рабочий репозиторий для совместной разработки Minecraft-ядра.
Связка: Hyperagent (облачная песочница) ↔ GitHub ↔ локальный ПК.

## Статус
Репозиторий инициализирован и готов к работе.

## Рабочий процесс
1. Агент пишет код в ветках и открывает Pull Request.
2. Ты подтягиваешь изменения локально через `git pull`.
3. Правки с ПК отправляются обратно через `git push`.
