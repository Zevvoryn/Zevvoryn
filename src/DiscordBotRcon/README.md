# Zevvoryn Discord RCON Bot + Web Panel (v1.2.0)

## Установка
```
cd DiscordBotRcon
npm install
cp .env.example .env   # заполните токен и ID
npm run deploy         # регистрация slash-команд
npm start              # запуск бота
```

## Проверка RCON (без Discord)
```
npm run rcon-test
npm run rcon-test -- "say Привет"
```

## Linux автозапуск (pm2)
```
npm install -g pm2
pm2 start index.js --name zevvoryn-bot
pm2 save && pm2 startup
```

## Windows
Автозапуск не поддерживается. Запускайте `npm start` вручную в отдельном терминале.

## Web Panel (WEBPANEL_V1)

Веб-консоль RCON в браузере. Слушает **ТОЛЬКО на 127.0.0.1** — снаружи недоступна.

### Запуск вместе с ботом
В `.env` установите:
```
WEB_ENABLED=true
WEB_PORT=3000
WEB_PASSWORD=мой_пароль   # оставьте пустым = без пароля
```

### Запуск отдельно
```
node webpanel.js
# или: npm run webpanel
```

### Доступ
- Локально: http://127.0.0.1:3000
- С удалённого VPS через SSH-туннель:
  ```
  ssh -L 3000:127.0.0.1:3000 user@ваш-сервер
  # затем в браузере: http://127.0.0.1:3000
  ```
- На Windows: просто откройте http://127.0.0.1:3000 в браузере

### Функции панели
- Терминал с подсветкой (тёмная тема)
- История команд (стрелки ↑↓)
- Быстрые кнопки: list, save-all, whitelist, time, weather, difficulty
- Длинные ответы разбиваются на части (2000 симв.)
- WebSocket — команды в реальном времени без перезагрузки
- Basic Auth (опционально через WEB_PASSWORD)
- Двойная проверка IP на уровне HTTP и WebSocket

## Discord slash-команды

| Команда | Описание | Требует admin |
|---------|----------|---------------|
| `/status` | Пинг сервера + список игроков | — |
| `/list` | Список игроков | — |
| `/say <текст>` | Сообщение всем | — |
| `/cmd <команда>` | **Любая** RCON-команда (autocomplete) | ✅ |
| `/tp <игрок> <цель>` | Телепорт | ✅ |
| `/give <игрок> <предмет> [кол-во]` | Выдать предмет | ✅ |
| `/kick <игрок> [причина]` | Выгнать | ✅ |
| `/gamemode <режим> [игрок]` | Режим (@a по умолч.) | ✅ |
| `/weather <clear/rain/thunder>` | Погода | ✅ |
| `/time <пресет>` | Время дня | ✅ |
| `/difficulty <0-3>` | Сложность | ✅ |
| `/whitelist <action> [ник]` | Белый список | ✅ |
| `/save` | Сохранить мир | ✅ |
| `/stop` | Остановить сервер | ✅ |

`/cmd` поддерживает **любую** команду сервера с autocomplete по частым командам.
Длинные ответы разбиваются на несколько сообщений автоматически.
